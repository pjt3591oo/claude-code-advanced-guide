# Design judgment

Read the current state through these relationships:

- **Intent:** what the person is trying to decide or do in this state.
- **Hierarchy:** which information deserves attention first; visual weight reveals whether the screen agrees.
- **Grouping:** which content and actions belong together. Spacing and alignment express ownership.
- **Affordance:** what an element invites the person to do. Its behavior must fulfill that promise.
- **Continuity:** how identity, place and unfinished work survive change.
- **Coherence:** the same role follows the same rule across screens, with deliberate differences where the work changes.

Treat a reference as evidence of relationships. Transfer a choice only when its reason holds in this product. Separate the visible cue from the inferred cause; test the choice with actual content and a state that could invalidate it.
