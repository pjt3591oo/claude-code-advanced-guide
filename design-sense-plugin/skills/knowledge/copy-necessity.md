# Copy necessity

Give each persistent text fragment a question to answer, including subtitles, metadata and status labels. Repeating the visible function adds reading without changing understanding. “Share ideas here” may repeat a channel's purpose; “External collaborators can read this channel” changes the decision to post. Their position is similar; their value is different.

A category label earns space when it changes interpretation or comparison. Translating an already clear category into another language solely to fill an eyebrow does not add information. Preserve multilingual names and terminology when the audience or subject needs them; language itself is not the defect.

Distinguish causes behind an empty surface. Before a search, the input may explain the next action. After no matches, show a useful way to change the query or filters. A failed request needs recovery rather than copy implying that no data exists.

Shortness is useful when it preserves meaning. Keep conditions that affect cost, timing or consequences. Place occasional details where people can reach them without repeating them in every row. Brand voice can carry character where it supports the subject; an unused description slot can stay empty.

When removing unnecessary copy leaves an awkward hole, revise the slot, spacing or component contract. A mandatory subtitle or empty-state paragraph can manufacture a need for filler. Represent absence as a valid composition; shortening the invented sentence leaves its false obligation intact.

Cover the sentence and read the screen again. If the next action or its interpretation changes, keep the fact responsible for that difference. If nothing changes, it is a removal candidate even when the wording sounds pleasant.
